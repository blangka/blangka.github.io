# 고양이 기사의 탐험

## 개요

Chrome 브라우저에서 바로 즐길 수 있는 웹 게임입니다.
키보드, 마우스, 모바일 터치로 모두 조작할 수 있습니다.

- 장르: 비행기 슈팅 게임
- 플랫폼: 웹 (Chrome, 모바일 브라우저)
- 조작: 키보드 / 마우스 / 모바일 터치
- 구성: 총 10개 챕터, 각 챕터마다 보스 등장

## 스토리

주인이 실수로 고양이를 잃어버렸습니다.
고양이는 주인을 찾아 집으로 돌아가려 하지만, 그 길은 생각보다 멀고 험난합니다.
현실에서 시작해 중세 시대의 모험을 거쳐, 다시 주인의 품으로 돌아오는 여정입니다.

### 챕터 한눈에 보기

배경은 숲, 마을, 들판, 늪, 바다, 화산, 성, 하늘 등 챕터마다 완전히 다른 분위기로 구성하고, 보스는 종류와 공격 방식이 겹치지 않게 했습니다.

| 챕터 | 시대 | 배경 | 보스 | 보스 특징 |
| --- | --- | --- | --- | --- |
| 1 | 현실 | 햇살 좋은 집 앞마당 | 이웃집 개 '멍멍이 대장' | 뼈다귀와 공을 던지는 돌진형 |
| 2 | 중세 | 달빛 아래 안개 낀 숲 | 늑대 대장 '그레이팽' | 빠르게 달려드는 속공형 |
| 3 | 중세 | 북적이는 성 아래 시장 | 쥐 왕 '래트킹' | 부하 쥐를 계속 불러내는 소환형 |
| 4 | 중세 | 황금빛 밀밭과 풍차 마을 | 멧돼지 장군 '아이언 터스크' | 풍차 날개 뒤에 숨어 돌진하는 방어형 |
| 5 | 중세 | 독안개 늪지대 | 거대 두꺼비 '보그' | 독 거품을 퍼뜨리는 범위형 |
| 6 | 중세 | 폭풍 치는 바다 위 해적선 | 문어 선장 '옥토 블랙비어드' | 여덟 개의 다리로 동시에 공격하는 다방향형 |
| 7 | 중세 | 용암이 흐르는 화산 협곡 | 불꽃 전갈 '스콜치' | 용암 바닥과 불꽃 꼬리를 쓰는 지형형 |
| 8 | 중세 | 어둠에 잠긴 마법의 성 | 까마귀 마법사 '레이븐' | 순간이동하며 마법진을 펼치는 마법형 |
| 9 | 중세 | 구름 위로 솟은 시간의 탑 | 늙은 용 '크로노스' | 시간을 느리게 하는 시간 조작형 |
| 10 | 현실 | 비 오는 동네에서 집으로 가는 길 | 폭풍 구름 '스톰' | 번개와 바람이 몰아치는 총공격형 |

### 챕터 1 - 햇살 좋은 집 앞마당

- 배경: 현실 세계, 햇살 좋은 집 앞마당
- 고양이는 주인에게 돌아가기 위해 앞마당을 지나갑니다.
- 적: 날아다니는 벌레, 새, 굴러오는 공 같은 일상의 장애물
- 보스: 앞마당을 지키는 이웃집 개 '멍멍이 대장'
- 챕터 1의 마지막까지 달성해도 주인을 만나지 못합니다.
- 대신 알 수 없는 빛에 휩싸여 중세 시대로 이동하게 됩니다.

### 챕터 2 - 달빛 아래 안개 낀 숲

- 배경: 중세 시대, 달빛이 비치는 안개 낀 숲
- 낯선 세상에서 눈을 뜬 고양이에게 숲의 늙은 수호자가 갑옷과 검을 건넵니다. 이때부터 '고양이 기사'가 됩니다.
- 적: 숲을 떠도는 도깨비불, 나무 정령
- 보스: 숲의 길목을 막고 있는 늑대 대장 '그레이팽'
- 그레이팽을 쓰러뜨리면 숲을 빠져나올 길이 열립니다.

### 챕터 3 - 북적이는 성 아래 시장

- 배경: 중세 시대, 상인과 마차로 북적이는 성 아래 시장 마을
- 마을 사람들이 곡식을 훔쳐 가는 쥐 떼 때문에 곤란해하고 있습니다.
- 적: 지붕 위를 달리는 쥐 도둑, 날아오는 항아리와 사과
- 보스: 쥐 떼를 이끄는 쥐 왕 '래트킹'
- 마을을 구하자 사람들이 "현실로 돌아가려면 '시간의 탑'을 찾아야 한다"고 알려줍니다.

### 챕터 4 - 황금빛 밀밭과 풍차 마을

- 배경: 중세 시대, 노을이 지는 황금빛 밀밭과 커다란 풍차가 있는 마을
- 시간의 탑으로 가는 길목에서 농부들이 사나운 멧돼지 무리에게 밭을 빼앗겨 울고 있습니다.
- 적: 밀밭을 가르며 달리는 멧돼지 새끼들, 바람에 날리는 허수아비
- 보스: 풍차 뒤에 진을 친 멧돼지 장군 '아이언 터스크'
- 돌아가는 풍차 날개가 공격을 막아 주기 때문에, 날개 사이의 틈을 노려야 합니다.

### 챕터 5 - 독안개 늪지대

- 배경: 중세 시대, 보라색 독안개가 피어오르는 늪지대
- 늪을 건너지 않으면 탑으로 갈 수 없습니다.
- 적: 독 거품, 모기떼, 늪에서 튀어 오르는 작은 개구리
- 보스: 늪의 주인 거대 두꺼비 '보그'
- 화면 곳곳에 퍼지는 독 거품 사이로 빈틈을 찾아 피해야 합니다.

### 챕터 6 - 폭풍 치는 바다 위 해적선

- 배경: 중세 시대, 거센 파도와 번개가 치는 바다
- 늪을 지난 고양이는 항구에서 해적선에 올라타고 바다를 건너 탑이 있는 땅으로 향합니다.
- 적: 대포를 쏘는 갈매기 해적, 파도 위를 튀어 오르는 날치떼
- 보스: 해적선을 집어삼키려는 문어 선장 '옥토 블랙비어드'
- 여덟 개의 다리가 화면의 여러 방향에서 동시에 날아옵니다.

### 챕터 7 - 용암이 흐르는 화산 협곡

- 배경: 중세 시대, 붉은 용암이 흐르는 화산 협곡
- 탑으로 가는 유일한 길이 화산 협곡을 지나갑니다.
- 적: 튀어 오르는 용암 덩어리, 불꽃 박쥐, 굴러떨어지는 화산암
- 보스: 협곡의 주인 불꽃 전갈 '스콜치'
- 보스가 용암을 끌어올려 화면 아래쪽 바닥이 위험해지므로, 위치 선정이 중요합니다.

### 챕터 8 - 어둠에 잠긴 마법의 성

- 배경: 중세 시대, 보랏빛 마법 등불만 깜빡이는 어둠의 성
- 탑 앞을 가로막은 성에는 마법에 홀린 병사와 유령이 가득합니다.
- 적: 마법에 홀린 갑옷 병사, 떠다니는 유령, 마법 구슬
- 보스: 고양이가 현실로 돌아가는 것을 막으려는 까마귀 마법사 '레이븐'
- 레이븐은 순간이동하며 화면에 마법진을 펼칩니다.

### 챕터 9 - 구름 위로 솟은 시간의 탑

- 배경: 중세 시대, 구름 위로 솟은 시간의 탑과 황금빛 하늘
- 탑 꼭대기에는 현실로 통하는 시간의 문이 있고, 문을 지키는 수호자가 있습니다.
- 적: 시계 톱니바퀴, 떠다니는 모래시계, 시간의 정령
- 보스: 시간의 문을 지키는 늙은 용 '크로노스'
- 크로노스는 시간을 느리게 만들어 고양이의 움직임을 방해합니다.
- 크로노스는 고양이의 용기를 확인하고 문을 열어 줍니다.
- 챕터 9를 달성하면 현실 세계로 돌아갈 수 있게 됩니다.

### 챕터 10 - 비 오는 동네, 주인과의 재회

- 배경: 현실 세계, 비가 내리는 저녁 동네에서 집으로 가는 길
- 현실로 돌아온 고양이는 주인이 비를 맞으며 자신을 애타게 찾고 있다는 것을 알게 됩니다.
- 적: 쏟아지는 빗방울, 날아다니는 낙엽, 번개
- 보스: 마지막 시련 폭풍 구름 '스톰'
- 폭풍을 뚫고 나아가면 구름이 걷히고 햇살이 비칩니다.
- 고양이가 주인을 찾아 품에 안기며 행복하게 마무리됩니다.

## 조작 방법

### 키보드

| 키 | 동작 |
| --- | --- |
| ↑ | 위로 이동 |
| ↓ | 아래로 이동 |
| ← | 왼쪽으로 이동 |
| → | 오른쪽으로 이동 |
| Q | 미사일 발사 |
| W | 폭탄 사용 |

### 마우스

| 입력 | 동작 |
| --- | --- |
| 마우스 움직임 | 마우스를 따라 캐릭터 이동 |
| Q 키 | 미사일 발사 |
| W 키 | 폭탄 사용 |

### 모바일 (터치)

| 입력 | 동작 |
| --- | --- |
| 원형 스틱 (조이스틱) | 상하좌우로 드래그하여 이동 |
| 미사일 버튼 | 터치하면 미사일 발사 |
| 폭탄 버튼 | 터치하면 폭탄 사용 |

## 무기와 아이템

적을 처치하면 일정 확률로 아이템이 랜덤하게 떨어집니다. 떨어진 아이템에 닿으면 획득합니다.

### 기본 무기

| 무기 | 키 | 설명 |
| --- | --- | --- |
| 미사일 | Q | 기본 공격 |
| 폭탄 | W | 사용하는 동안 무적, 화면의 적에게 큰 피해 |

### 강화 무기 (공격 강화)

| 아이템 | 효과 |
| --- | --- |
| 멀티샷 | 미사일이 2발, 3발로 늘어나 넓게 퍼져 나감 |
| 파워업 | 미사일의 공격력이 올라감 |
| 관통탄 | 미사일이 적을 뚫고 지나가 여러 적을 한 번에 공격 |
| 유도탄 | 미사일이 가까운 적을 따라가서 공격 |
| 연사 강화 | 미사일 발사 속도가 빨라짐 |

### 방어 무기 (방어 강화)

| 아이템 | 효과 |
| --- | --- |
| 방어막 | 적의 공격을 한 번 막아 줌 |
| 체력 회복 | 체력을 조금 회복 |
| 자석 | 주변에 떨어진 아이템을 끌어당김 |

### 기타 아이템

| 아이템 | 효과 |
| --- | --- |
| 폭탄 보급 | 폭탄 개수 +1 |

### 규칙

- 강화 무기는 일정 시간 동안 유지되며, 같은 강화 아이템을 또 먹으면 단계가 올라갑니다.
- 공격을 받으면 강화 단계가 한 단계 내려갑니다.
- 보스 처치 시에는 아이템이 반드시 하나 떨어집니다.

## 게임 방법

1. 비행기를 조종해 날아오는 적을 미사일로 처치합니다.
2. 게임은 총 10개의 챕터로 이루어져 있습니다.
3. 각 챕터의 끝에는 보스가 있으며, 보스를 처치하면 다음 챕터로 넘어갑니다.
4. 폭탄을 사용하는 동안에는 무적 상태가 됩니다.
5. 중간중간 적을 처치하면 폭탄이 떨어지기도 합니다.
6. 적을 처치하면 강화 무기나 방어 무기가 랜덤으로 떨어지며, 획득하면 더 강해집니다.

## 구현 현황

게임 파일은 `limchaehong/` 폴더에 있고, 접속 주소는 `/limchaehong/`입니다.

| 파일 | 역할 |
| --- | --- |
| `index.html` | 게임 화면 (캔버스와 모바일 터치 컨트롤) |
| `style.css` | 화면 배치, 모바일 스틱/버튼 스타일 |
| `chapters.js` | 챕터 데이터 (배경, 적, 보스). 새 챕터는 여기에 추가 |
| `game.js` | 게임 규칙 (이동, 발사, 폭탄, 아이템, 보스 패턴, 화면 전환) |

| 챕터 | 상태 |
| --- | --- |
| 1 - 집 앞마당 | 구현 완료 (플레이 가능) |
| 2 ~ 10 | 준비 중 (챕터 1 클리어 시 "To be continued" 화면) |

### 챕터 1 구현 내용

- 진행: 약 60초 동안 적이 나오고, 이후 WARNING 경고와 함께 보스가 등장합니다.
- 적: 벌(🐝, 좌우로 흔들며 내려옴), 새(🐦, 플레이어를 향해 발사), 공(⚽, 벽에 튕김)
- 보스 '이웃집 개 멍멍이 대장'(🐕): 체력 90
  - 부채꼴 뼈다귀 발사, 원형 뼈다귀 발사, 플레이어를 향해 돌진(돌진 직전에 붉은 경고선 표시)
  - 체력이 절반 이하가 되면 탄이 늘어나고 패턴 간격이 짧아집니다.
- 보스를 처치하면 아이템 3개가 떨어지고, 남은 체력 1칸당 300점이 보너스입니다.
- 클리어 후 "중세 시대로 이동" 스토리 화면이 나옵니다.

### 수치 (현재 설정)

| 항목 | 값 |
| --- | --- |
| 시작 체력 / 최대 체력 | 3 / 5 |
| 시작 폭탄 / 최대 폭탄 | 2 / 5 |
| 폭탄 무적 시간 | 3초 (사용 시 화면의 적 탄 제거, 적과 보스에 피해) |
| 피격 후 무적 | 약 1.6초 (방어막으로 막으면 1초) |
| 강화 무기 | 최대 3단계, 한 단계당 25초 유지 |
| 아이템 드롭 | 적 처치 시 약 10% (새·공은 더 높음), 보스는 3개 확정 |

### 기타 동작

- 일시정지: `P` 또는 `Esc` (모바일은 우측 상단 일시정지 버튼), 창을 벗어나면 자동 일시정지
- 최고 점수는 브라우저에 저장됩니다.
- 게임오버 시 해당 챕터의 처음부터 다시 시작합니다. (점수는 챕터 시작 시점으로 복구)
- 마우스는 움직이는 동안 고양이가 따라오고, 방향키를 누르면 키보드 조작으로 바뀝니다.

## 메모

- 보스 체력과 탄 속도는 자동 플레이 테스트로 조정했습니다. 실제로 해 보고 너무 쉽거나 어려우면 알려주세요.
- 챕터 2~10은 위 스토리 표의 배경과 보스를 기준으로 `chapters.js`에 하나씩 추가할 예정입니다.
