# 태리가 만든 라부부랑 자동차 대결

## 개요

태리가 만든 라부부와 자동차 경주를 하는 어린이용 웹 게임입니다.
**왼쪽, 오른쪽 키만** 누르면 되는 아주 단순한 조작이라서 어린이도 쉽게 할 수 있습니다.

- 장르: 어린이용 자동차 레이싱 (위에서 아래로 달리는 화면)
- 플랫폼: 웹 (Chrome, 모바일 브라우저)
- 접속 주소: `/tr/`
- 조작: 왼쪽 / 오른쪽 키(모바일은 왼쪽 / 오른쪽 버튼) 두 개뿐

## 등장인물

### 임태리 (주인공)

- 자동차 경주를 하는 **7살 여자아이**입니다.
- 이름이 눈에 띄게 붙어 있습니다.
  - 자동차 뒤쪽 번호판에 **"임태리"**
  - 자동차 위에 따라다니는 이름표 **"임태리"**
  - 타이틀과 결과 화면의 가슴 이름표 **"임태리"**
- 양쪽으로 묶은 머리에 분홍 리본, 분홍색 자동차를 탑니다.

### 라부부 (상대)

- 귀엽게 그린 라부부입니다. 길쭉하고 뾰족한 귀, 크고 동그란 눈, 볼터치, 동글동글한 얼굴에 삐죽삐죽 이빨이 보이는 웃는 입을 가졌습니다.
- 민트색 자동차를 타고, 번호판은 **"라부부"**입니다.
- 무섭지 않은 친구 같은 경쟁 상대입니다. 가끔 혼자 넘어져서(😵) 태리가 따라잡을 기회를 줍니다.

## 조작 방법

### 키보드

| 키 | 동작 |
| --- | --- |
| ← | 자동차가 왼쪽으로 이동 |
| → | 자동차가 오른쪽으로 이동 |

- 자동차는 **저절로 앞으로 달립니다.** 가속이나 브레이크 키는 없습니다.
- 시작, 다음 코스, 다시 하기도 **← → 키나 화면 터치**로 합니다. (다른 키는 필요 없습니다.)
- `P` / `Esc`: 잠깐 멈춤, `M`: 소리 켜고 끄기 (선택 기능)

### 모바일 (터치)

| 입력 | 동작 |
| --- | --- |
| 화면 아래 왼쪽 큰 버튼 (◀) | 왼쪽으로 이동 |
| 화면 아래 오른쪽 큰 버튼 (▶) | 오른쪽으로 이동 |
| 화면의 왼쪽 / 오른쪽 절반을 누르고 있기 | 같은 방향으로 이동 |

버튼은 어린이 손가락으로도 누르기 쉽게 아주 크게 만듭니다.

## 게임 규칙

1. 3, 2, 1, 출발! 라부부와 나란히 출발합니다.
2. 왼쪽 / 오른쪽으로만 움직여서 **도착선에 먼저 들어오면 승리**입니다.
3. 길에 있는 **별(⭐)**을 먹으면 모읍니다. **별 5개를 모으면 부스트**가 자동으로 켜져서 잠깐 아주 빨라집니다.
4. 길 위의 **화살표 판**을 밟으면 짧게 빨라집니다.
5. **장애물**(고깔, 바위, 웅덩이 등)에 부딪히면 잠깐 느려집니다. 하지만 **게임이 끝나지 않습니다.** 어린이가 실패해서 속상하지 않도록 느려지기만 합니다.
6. 라부부는 장애물을 알아서 피해 가고, 너무 앞서거나 너무 뒤처지면 속도가 조금 조절되어 끝까지 접전이 됩니다.
7. 라부부가 먼저 도착하면 "아깝다!" 하고 같은 코스를 다시 도전합니다.

## 코스

총 3개 코스입니다. 뒤로 갈수록 길이 길어지고 장애물이 늘고 라부부가 조금 빨라집니다.

| 코스 | 이름 | 분위기 | 장애물 |
| --- | --- | --- | --- |
| 1 | 동네 놀이터 길 | 초록 잔디, 나무, 꽃, 집 | 고깔, 바위, 웅덩이 |
| 2 | 반짝반짝 바닷가 | 모래사장, 야자수, 조개 | 꽃게, 비치볼, 양동이, 웅덩이 |
| 3 | 무지개 하늘길 | 구름 위 사탕 길, 무지개, 풍선 | 막대사탕, 도넛, 컵케이크, 웅덩이 |

3개 코스를 모두 이기면 **"태리는 챔피언!"** 엔딩이 나옵니다.

## 구현 현황

게임 파일은 `tr/` 폴더에 있고, 위의 내용이 모두 구현되어 있습니다. 접속 주소는 `/tr/`입니다.

| 파일 | 역할 |
| --- | --- |
| `index.html` | 게임 화면 (캔버스, 모바일 좌우 버튼, 소리 버튼) |
| `style.css` | 화면 배치, 모바일 버튼 스타일 |
| `game.js` | 게임 규칙, 태리와 라부부 그림, 자동차, 코스, 화면 |
| `sound.js` | 배경음악과 효과음 |
| `document/game-tr.md` | 이 문서 |

### 조작 방식 (구현된 동작)

- 자동차는 3개 차선 위를 달립니다. ← 한 번 누르면 왼쪽 차선으로, → 한 번 누르면 오른쪽 차선으로 **한 칸** 움직입니다.
- 버튼을 **꾹 누르고 있으면** 계속 한 칸씩 움직입니다. 그래서 여러 칸을 가고 싶을 때는 길게 누르면 됩니다.
- 모바일은 화면 아래에 크고 둥근 ◀(분홍) / ▶(파랑) 버튼이 나옵니다. 버튼 말고 **화면의 왼쪽/오른쪽 절반을 눌러도** 같은 동작입니다.
- 타이틀, 코스 사이, 결과 화면은 ← → 키(또는 화면 터치)로 넘어가고, 화면에 키 그림으로 안내가 나옵니다.

### 길 위의 물건

| 물건 | 효과 |
| --- | --- |
| ⭐ 별 | 먹으면 위쪽 별 칸이 하나 채워지고, 5개가 모이면 부스트(약 2.4초, 속도 1.6배) |
| 초록 화살표 판 | 밟으면 약 1.1초 동안 빨라짐 (1.4배) |
| 장애물 (코스마다 다름) | 부딪히면 약 1.1초 동안 속도가 반 이하로 느려지고 자동차가 어질어질 흔들림. **게임오버 없음** |
| 물웅덩이 | 지나가면 잠깐(약 0.8초) 느려짐 |

### 라부부의 움직임

- 앞에 있는 장애물을 보고 알아서 피해 가지만, 코스마다 일정 확률로 실수해서 부딪힙니다. (코스 1: 15%, 코스 2: 12%, 코스 3: 10%)
- 가끔 혼자 넘어져서(😵 표정) 잠깐 거의 멈춥니다. 6~10초에 한 번 정도입니다.
- 태리가 많이 앞서면 조금 느려지고, 많이 뒤처지면 조금 빨라져서 끝까지 접전입니다.
- **같은 코스에서 계속 지면** 라부부가 조금씩 천천히 달립니다. (한 번 질 때마다 약 4.5%, 최대 20%) 이길 때까지 포기하지 않고 도전할 수 있게 하기 위한 장치입니다. 졌을 때 "이번엔 라부부가 조금 천천히 달려요" 라고 알려 줍니다.

### 그림

- 모든 그림은 둥근 한글 글꼴(Jua)과 통통한 갈색 윤곽선으로 그린 동화풍입니다.
- **임태리**: 양쪽으로 묶은 갈색 머리에 분홍 리본, 분홍색 자동차. 자동차 번호판, 자동차 위 이름표, 타이틀·결과 화면의 이름표에 모두 "임태리"가 붙어 있습니다.
- **라부부**: 길고 뾰족한 귀(안쪽은 분홍), 크고 동그란 눈, 볼터치, 복슬복슬한 볼 털, 삐죽삐죽한 이빨이 보이는 웃는 입. 민트색 자동차, 번호판과 이름표는 "라부부".
- 표정: 평소 웃는 얼굴 / 부스트·승리 때 신난 얼굴 / 장애물이나 넘어졌을 때 어질어질(×× 눈과 빙글빙글 도는 별) / 졌을 때 속상한 얼굴.

### 소리

- 배경음악: 타이틀, 코스 1·2·3, 엔딩이 모두 다른 곡입니다. 외부 음악 파일 없이 브라우저에서 직접 만들어 재생하며, 어린이 게임이라 밝고 부드럽게만 만들었습니다. 부스트 중에는 음악이 조금 빨라집니다.
- 효과음: 카운트다운, 출발, 별 먹기, 부스트, 속도판, 장애물 부딪힘, 물웅덩이, 라부부가 넘어짐, 차선 이동, 승리, 패배, 메뉴 선택.
- 소리는 브라우저 규칙상 **첫 키 입력이나 터치 뒤에** 시작됩니다. `M` 키 또는 화면 오른쪽 위 스피커 버튼으로 켜고 끌 수 있고, 설정은 저장됩니다.

### 기타 동작

- 일시정지: `P` / `Esc`. 창을 벗어나거나 다른 탭으로 가면 자동으로 멈춥니다. (멈춘 뒤 ← → 키나 화면 터치로 계속)
- 경주 중 라부부가 화면 밖 앞쪽에 있으면 위쪽에 "앞이야!" 하고 얼굴이 표시됩니다.
- 코스 1부터 순서대로 진행하고, 지면 같은 코스를 다시 합니다. 코스 3까지 이기면 엔딩이 나옵니다. 엔딩에서 → 를 누르면 타이틀로 돌아갑니다.
